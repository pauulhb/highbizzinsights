# Final UAT Plan

Pilot group:
- 5–10 KAMs
- 2 managers
- 1 regional head
- 1 management user

Duration:
10 working days

Critical validations:
- first customer creation
- duplicate warning
- repeat search
- GPS check-in/check-out
- 14:59 vs 15:00
- short-visit reason
- one active visit only
- samples/feedback
- leads/pipeline
- orders
- follow-ups
- offline queue
- timeline
- DWR
- manager hierarchy
- customer reassignment
- session refresh/logout
- reports

Release threshold:
No open critical defects.
High defects closed or formally accepted.
Report totals reconciled.
No data-loss issue.
No unauthorized data access.
