# Field Sales CRM v1.0 Candidate

This package consolidates the project into one release-candidate structure for controlled UAT and final hardening.

Core flow:
- Login
- Start Day
- First-time customer creation
- Customer search
- GPS check-in
- Server-side visit timer
- 15-minute qualified-visit rule
- Visit report
- Samples / feedback
- Leads / pipeline
- Orders
- Follow-ups
- Customer timeline
- DWR
- Management reporting
- Offline sync queue
- Role hierarchy

Important:
This remains brand-neutral. Final app name/logo/company identity can be applied after approval.

This is a release-candidate source package, not a signed App Store/Play Store binary.
