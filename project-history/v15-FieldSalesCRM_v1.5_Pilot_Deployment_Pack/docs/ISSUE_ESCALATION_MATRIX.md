# Issue Escalation Matrix

Critical — immediate:
- login/security bypass
- unauthorized data exposure
- data loss
- visit rule bypass
- duplicate order caused by sync
- app blocks all users

High — same working day:
- report totals materially wrong
- customer ownership/reassignment wrong
- sync repeatedly failing
- customer timeline missing business events

Medium — next sprint:
- workflow inconvenience with workaround
- notification delay
- export formatting problem

Low:
- cosmetic/text/spacing
