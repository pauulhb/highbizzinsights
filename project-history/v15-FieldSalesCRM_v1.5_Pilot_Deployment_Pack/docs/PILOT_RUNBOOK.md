# Pilot Runbook

Morning:
1. Confirm API/DB health.
2. Review previous-day sync backlog.
3. Confirm pilot users can login.
4. Confirm no unresolved Critical defect.

During day:
- KAMs use app normally.
- Do not instruct users to manipulate phone clock/GPS.
- Log field issues immediately.
- Preserve failed sync records for diagnosis.

Evening:
1. Review total vs qualified visits.
2. Review short-visit reasons.
3. Review geofence exceptions.
4. Review samples/leads/orders.
5. Reconcile one KAM report against source activity.
6. Triage defects.
