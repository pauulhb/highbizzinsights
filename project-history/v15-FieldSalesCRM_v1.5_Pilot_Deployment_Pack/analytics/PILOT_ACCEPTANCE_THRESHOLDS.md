# Pilot Acceptance Thresholds

Mandatory:
- 0 Critical security/data-loss defects
- 0 unauthorized data visibility incidents
- 0 duplicate orders caused by sync
- 14:59 never Qualified
- 15:00 always Qualified
- 100% Short Visits contain a reason

Recommended:
- Sync success >= 98%
- Report reconciliation variance <= 1%
- Crash-free pilot sessions >= 99%
- Repeat-visit workflow typically <= 90 seconds for data entry after meeting
- Sample follow-up linkage >= 95%
