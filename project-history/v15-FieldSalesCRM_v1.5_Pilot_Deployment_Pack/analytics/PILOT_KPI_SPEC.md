# Pilot KPI Specification

Adoption:
- Daily active KAM %
- Start Day completion %
- End/report completion %

Visit quality:
- Total visits
- Qualified visits
- Short visits
- Qualified visit %
- Average qualified visit duration
- Geofence exception %

CRM quality:
- New customers
- Duplicate warning count
- Repeat customers
- Samples
- Sample feedback completion %
- Leads
- Pipeline value
- Orders
- Order value
- Follow-up completion %

System quality:
- Offline queued records
- Sync success %
- Sync retry count
- Duplicate sync records (target = 0)
- Crash/blocker count
- Average API latency

Management:
- Report reconciliation variance
- Unauthorized access incidents (target = 0)
