# Management Dashboard
Drill-down: Region -> State -> HQ -> KAM -> Customer -> Visit.

KPIs: total visits, qualified visits >=15 min, short visits, qualification %, unique accounts,
new accounts, doctor/hospital/distributor mix, samples and feedback, leads, pipeline,
conversion, orders/value, due/overdue follow-ups, geofence exceptions and average visit duration.

Periods: Daily, Weekly, Monthly, Quarterly, Yearly.
Exceptions: repeated short visits, weak coverage, high geofence exceptions, samples without feedback,
stale leads, overdue follow-ups and high activity with low conversion.
