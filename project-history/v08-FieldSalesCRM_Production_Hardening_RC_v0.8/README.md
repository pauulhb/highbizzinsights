# Field Sales CRM v0.8
Production-hardening release-candidate package for the brand-neutral Android/iOS field-sales CRM.

Adds role-based management scope, one-active-visit protection, reassignment approvals, audit logging,
offline conflict rules, attachment architecture, security guidance, management KPI specification,
UAT defect tracking and release controls.

The 15-minute (900-second) qualified-visit rule remains server-authoritative.
