# Production Candidate Smoke Test

After deployment, before user rollout:

1. Health/readiness endpoints.
2. Login with controlled test account.
3. Customer search.
4. Create controlled test customer.
5. GPS check-in.
6. Verify second active visit blocked.
7. Complete a Short Visit with reason.
8. Complete a >=15 minute controlled Qualified Visit.
9. Add sample/lead/order/follow-up.
10. Verify customer timeline.
11. Verify manager drill-down.
12. Verify CSV/PDF export as configured.
13. Verify attachment upload.
14. Verify offline sync retry.
15. Verify logout/session revocation.
16. Remove/close controlled test records according to approved policy.
