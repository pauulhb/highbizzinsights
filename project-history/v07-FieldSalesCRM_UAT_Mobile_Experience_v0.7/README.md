# Field Sales CRM — UAT Mobile Experience v0.7

This release connects the mobile workflow to the v0.6 API foundation and adds UAT-focused mobile behaviour.

Included:
- API-connected login
- customer creation/search/profile
- customer timeline
- GPS visit check-in/check-out
- live 15-minute visit timer
- geofence exception display
- commercial actions
- report screens
- manager screen
- customer cache
- offline sync queue
- batch sync
- follow-up and commercial update APIs
- multiple practice location API
- UAT checklist and sample account plan

Important:
The server remains authoritative for the 15-minute productive-visit rule.
