# UAT Defect Closure Workflow

1. Log defect.
2. Assign severity.
3. Reproduce.
4. Fix in development.
5. Deploy to UAT.
6. Retest by original tester where possible.
7. Mark Closed only after evidence.
8. Run regression for affected modules.
9. Keep Critical/High defect summary for release decision.

No v1.0 production release with open Critical defects.
