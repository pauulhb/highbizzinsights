# Field Sales CRM v0.9 — Pilot Build

This package consolidates the project into a pilot-oriented release structure for controlled field testing.

Pilot scope:
- Android/iOS mobile CRM
- KAM login and hierarchy
- first-time customer creation
- customer search and repeat visits
- GPS check-in/check-out
- server-authoritative 15-minute Qualified Visit rule
- samples, feedback, leads, orders and follow-ups
- daily/weekly/monthly/quarterly/yearly reporting
- management drill-down
- offline queue/sync architecture
- customer reassignment
- audit controls
- UAT defect tracking

Important:
This package is source/configuration for a pilot build. Producing a signed Android APK/AAB or iOS TestFlight build
requires an installed mobile build toolchain, signing credentials and production/UAT environment values.
