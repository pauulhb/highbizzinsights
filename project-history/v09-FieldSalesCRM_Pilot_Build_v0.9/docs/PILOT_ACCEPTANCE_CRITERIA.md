# Pilot Acceptance Criteria

A pilot can be considered successful when:

- 100% of valid visits preserve server timestamps.
- 14:59 never counts as Qualified.
- 15:00 or more counts as Qualified.
- Short visits always contain a reason.
- Parallel active visits are blocked.
- GPS check-in/check-out records are captured for visit completion.
- Customer duplication is flagged before creation.
- Offline records sync without duplicate server records.
- Sample feedback remains linked to customer history.
- Leads and orders appear in the customer timeline.
- DWR totals reconcile with transaction records.
- Manager visibility follows reporting hierarchy.
- KAM cannot access unauthorized accounts.
- No critical data-loss defect remains open.
