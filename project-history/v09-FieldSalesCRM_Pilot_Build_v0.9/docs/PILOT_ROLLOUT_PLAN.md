# Pilot Rollout Plan

## Phase 1 — Internal UAT
Recommended users:
- 2 KAMs
- 1 Area Manager
- 1 State/Regional Manager
- 1 Management user

Duration:
5–7 working days

Validate:
- login
- customer creation
- repeat search
- GPS pin
- 15-minute rule
- short-visit reasons
- samples
- leads
- orders
- follow-ups
- offline mode
- reports
- management visibility

## Phase 2 — Controlled Field Pilot
Recommended users:
5–10 KAMs across 2 HQs.

Duration:
2 weeks.

Measure:
- app adoption
- average report-entry time
- GPS exception rate
- qualified visit rate
- sync failures
- duplicate customer rate
- sample follow-up completion
- lead conversion
- order capture completeness

## Phase 3 — Pilot Review
Management reviews:
- defects
- field usability
- data accuracy
- reporting accuracy
- permission issues
- territory logic
- battery/network impact

## Phase 4 — v1.0 Freeze
Only after critical/high UAT defects are closed.
