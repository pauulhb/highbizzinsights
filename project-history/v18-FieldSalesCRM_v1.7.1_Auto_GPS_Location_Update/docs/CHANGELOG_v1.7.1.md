# v1.7.1 Changes

Changed customer location design from manually adjustable mapping to automatic GPS capture.

New safeguards:
- no manual latitude/longitude
- no draggable customer pin
- automatic device GPS capture
- GPS accuracy and timestamp
- locked Google Maps marker
- repeat-visit distance validation
- Location Exception classification
- alternate locations stored separately
- independent Check-In and Check-Out GPS
- no continuous background employee tracking required

Unchanged:
Qualified Visit requires >=900 seconds.
