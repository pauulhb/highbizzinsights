# Attachment UI Flow

Supported:
- Purchase Order
- Quotation
- Business Card
- Customer Document

Mobile flow:
1. User taps Attach.
2. Choose category.
3. Select camera/file source.
4. App validates file size/type.
5. App requests upload intent.
6. App uploads binary to signed URL.
7. App confirms metadata.
8. Customer timeline shows attachment event.

Recommended limits for pilot:
- max 10 MB per file
- PDF/JPG/PNG
- no executable files
