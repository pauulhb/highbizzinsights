# Field Sales CRM — Commercial CRM v0.4

This release layers commercial CRM functionality on top of the field workflow.

Included:
- Product master
- Samples and feedback
- Automatic sample follow-up
- Leads and pipeline
- Orders
- Follow-ups
- Automatic DWR service
- Management KPI dashboard
- 15-minute qualified visit rule retained

This is still source code and architecture, not a deployed production app.

The next milestone is v0.5: hierarchy, territory management, real persistence for all commercial modules, background sync, reporting filters, management drill-down and notification scheduling.
