# Pilot Event Catalog

Recommended operational events:
- login_success
- login_failure
- start_day
- end_day
- customer_created
- duplicate_warning
- visit_checkin
- visit_geofence_exception
- visit_short
- visit_qualified
- sample_created
- sample_feedback_updated
- lead_created
- lead_stage_changed
- order_created
- followup_completed
- sync_queued
- sync_succeeded
- sync_failed
- report_viewed

Do not capture unnecessary free-text meeting notes in telemetry.
