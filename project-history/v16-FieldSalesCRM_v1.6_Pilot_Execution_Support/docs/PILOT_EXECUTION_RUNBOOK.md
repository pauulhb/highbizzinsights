# Pilot Execution Runbook

Daily morning:
1. Check API /ready.
2. Check database health.
3. Review unresolved Critical/High defects.
4. Review prior-day sync backlog.
5. Confirm pilot users can login.

During field day:
- Users follow normal field workflow.
- Do not manipulate device clock/GPS.
- Log blockers immediately.
- Preserve failed records for diagnosis.

Daily evening:
1. Review KAM scorecards.
2. Review short visits.
3. Review geofence exceptions.
4. Review samples/leads/orders.
5. Review sync health.
6. Reconcile at least one KAM's report.
7. Triage defects.
