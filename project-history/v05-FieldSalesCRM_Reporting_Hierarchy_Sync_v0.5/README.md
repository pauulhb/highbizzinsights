# Field Sales CRM — Reporting, Hierarchy & Sync v0.5

This release adds the management structure and reporting foundation required to operate the mobile CRM at scale.

Included:
- Employee reporting hierarchy
- State / HQ / city territory model
- Customer ownership and reassignment-ready design
- Multiple customer practice locations
- Unified customer timeline
- Daily/Weekly/Monthly/Quarterly/Yearly report filters
- Region/State/HQ/KAM visibility logic
- CSV export service
- Offline sync queue and idempotency pattern
- Follow-up notification logic
- Audit schema
- API contract for team, territory, timeline, reporting, export and sync

The 15-minute Qualified Visit rule remains unchanged and continues to be enforced as the core productivity standard.

Next milestone: v0.6 will connect the mobile code to a real backend API and turn the current architecture into an end-to-end deployable system.
