# Reporting Specification

## Daily Work Report
Per KAM:
- Start Day
- End Day
- Total Accounts Visited
- Qualified Visits >= 15 min
- Short Visits < 15 min
- Qualified Visit Rate
- Unique Customers
- Doctors
- Hospitals
- Distributors
- New Customers
- Samples Given
- Sample Feedback
- Leads Created
- Pipeline Value
- Orders
- Order Value
- Follow-ups Created / Completed

## Weekly / Monthly / Quarterly / Yearly
All daily metrics aggregate by period and can be filtered by:
- Region
- State
- HQ
- KAM
- Customer Type
- Customer
- Product

## Management Drill-down
Region -> State -> HQ -> KAM -> Customer -> Visit

## Core KPI rule
Only visits lasting 15 minutes or more count as Qualified/Productive Visits.
Short visits remain visible separately and never disappear from the audit trail.
