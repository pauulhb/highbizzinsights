# FieldSalesCRM

A field sales CRM for pharma/medical KAMs — customer creation with GPS
pinning, GPS-verified visit check-in/check-out, a 15-minute qualified visit
rule, geofence Location Exceptions, offline-first sync, commercial CRM
(samples/feedback/leads/orders), DWR reporting, and a manager hierarchy
drill-down.

- **`mobile/`** — the Flutter app. See `mobile/README.md` to run it or build
  an APK.
- **`.github/workflows/build-apk.yml`** — builds a release APK on every push
  to `mobile/**` and publishes it as a workflow artifact.
- **`project-history/`** — the 17 original milestone snapshots (v0.1
  prototype through v1.7.1) this app was consolidated from, kept for
  reference.
